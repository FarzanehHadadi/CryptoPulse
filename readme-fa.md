# CryptoPulse

> پلتفرم مانیتورینگ، تحلیل و هشدار بازار ارزهای دیجیتال با زبان Go

## معرفی پروژه

CryptoPulse یک پروژه بک‌اند است که با هدف جمع‌آوری اطلاعات بازار کریپتو، تحلیل داده‌ها و تولید هشدارهای هوشمند طراحی می‌شود.

هدف این پروژه ساخت یک **ربات معامله‌گر** نیست؛ بلکه ایجاد یک **سیستم تحلیل بازار (Market Intelligence Platform)** است که بتواند وضعیت بازار را بررسی کرده و اطلاعات قابل استفاده در اختیار معامله‌گر قرار دهد.

---

# اهداف پروژه

- دریافت اطلاعات بازار به صورت لحظه‌ای
- ذخیره تاریخچه قیمت‌ها
- تحلیل تکنیکال
- تولید سیگنال
- ارسال هشدار
- ارائه API برای داشبورد
- یادگیری معماری حرفه‌ای Go

# چشم‌انداز

هدف نهایی این پروژه ساخت یک نمونه‌کار حرفه‌ای برای یادگیری Go و معماری سیستم‌های Backend است؛ پروژه‌ای که به‌صورت مرحله‌ای از یک Monolith ساده به یک سیستم توزیع‌شده با gRPC، Kafka و Kubernetes تکامل پیدا می‌کند.
